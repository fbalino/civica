# Pulse source-coverage shared-contract release note

**Contract version:** `civica-index-api-contract-pulse-source-coverage-v1`

Pulse runtime method `pulse-v2.4-beta` renames the historical `activeProduction` source set to `observedEvidence` and adds declared connector blind spots. The new `/api/v1/pulse/source-coverage` endpoint publishes live operating/degraded/inactive states from connector telemetry, retained evidence, and rights.

No source-native Governance Evidence Dashboard field, country grade, rank, or scalar score changes. Pulse numeric effects remain API-only experimental research.
