# Pulse information-context shared-contract v6 release note

**Contract version:** `civica-index-api-contract-pulse-information-context-v6`

The country-dimensions API exposes `pulse-information-environment-context/v1`. Missing context remains null throughout the object and has no numeric effect. An observed value is valid only with complete source, release, observation vintage, retrieval time, content hash, and coverage metadata.

The Pulse runtime method is `pulse-v2.6-beta`. Its registered RSF candidate release is blocked from production use pending rights clearance and validation. Country values are not redistributed. The legacy multiplier design is available only as a sensitivity scenario and is not a calibrated correction.
