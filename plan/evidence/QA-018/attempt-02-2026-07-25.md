## Abort

The runner committed `0033_flat_hardball`, `0034_superb_the_fallen`, and
`0035_equal_marvex`. Migration `0036_moaning_toad_men` then failed with
PostgreSQL code `P0001` and the bounded message that the named Beta-R3 frozen
vintage is immutable. Its transaction rolled back. A follow-up plan-only read
confirmed 36 applied ledger rows and `0036` plus the remaining 11 migrations
still pending.

The cause was a migration-contract collision. DAT-023 correctly rejects every
mutation of a named frozen `ci_composite_scores` row, while PLT-014 must bind
those same preserved rows to their newly registered release header by changing
only the new nullable `release_id` column. The corrected migration pauses only
that named trigger around the exact one-column backfill. PostgreSQL retains an
exclusive table lock until the transaction commits, and rollback restores both
the trigger state and rows together. A regression test pins the trigger order,
the narrow update predicate, and immediate re-enable.

failed child branch was permanently deleted immediately after the failure was
recorded, invalidating its credential, and the local temporary environment file
