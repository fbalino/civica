## Abort

The runner committed `0033_flat_hardball`, `0034_superb_the_fallen`, and
`0035_equal_marvex` on the disposable branch. Migration
`0036_moaning_toad_men` then failed with PostgreSQL code `42601` and the bounded
message `syntax error at or near "publication"`. Its transaction rolled back.
A second plan-only read confirmed 36 applied ledger rows and `0036` plus the
remaining 11 migrations still pending.

The cause was local and reproducible: `splitPostgresStatements()` treated the
semicolon in this SQL line comment as a statement terminator:

```sql
-- harmless; publication remains an explicit, separately verified operation.
```

That produced a malformed query beginning `publication remains`. The splitter
now tracks PostgreSQL line comments and nested block comments in addition to
strings, quoted identifiers, and dollar-quoted bodies. Focused fixtures cover
the real `0036` shape and reject a recurrence without changing the immutable
migration SQL or its registered hash.
