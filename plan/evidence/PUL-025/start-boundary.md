# PUL-025 start boundary

The protocol lock is not the prospective start. As of 2026-07-12, the status is
`preregistered_not_started`.

PUL-040 must calculate the earliest compliant start from live stage evidence.
The current production classifier does not yet have a successful scheduled run
under `pulse-v2.15-beta`; the 2026-07-12 scheduled attempt ended without claiming
a cluster or recording a model attempt. Starting or backdating the clock would
therefore violate the preregistered prerequisites.

No paid model call is authorized by PUL-025. A later bounded classifier run
requires task-specific owner approval with providers, models, call count, and a
hard spending cap, or the scheduled route must succeed without manual action.
