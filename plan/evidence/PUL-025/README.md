# PUL-025 evidence

PUL-025 replaces the former single backtest claim with a locked three-lane
validation design. The canonical protocol is
`plan/research/pulse-validation-protocol-v1.md`; its deterministic registry is
`data/research/pulse-validation-protocol-v1.json`.

## Result

- Ten famous historical shocks are regression fixtures with no inferential use.
- The retrospective lane binds the previously frozen 90-day event-candidate,
  system-negative, and country-day frames.
- Error roles include spurious dimensions, missed events, retrieval misses,
  wrong jurisdictions, false abstentions, deduplication failures, and
  publication errors.
- The 90-day prospective lane freezes all production stages and retained
  evidence before independent human labels are opened.
- Any semantic method change ends the prospective window and requires a new
  protocol version.
- The protocol remains `preregistered_not_started`; PUL-040 owns the start
  decision and PUL-018/019/026 own evaluation and reporting.
