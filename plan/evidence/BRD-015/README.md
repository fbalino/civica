# BRD-015 — copyright/trademark/data-rights complaint handling

Completed 2026-07-12. Process at `data/COMPLAINT-HANDLING.md`.

Documents the eight required stages — authenticate the claim, preserve
evidence, temporary containment, legal/editorial review, counter-notice/appeal,
final action, requester response, public correction & version history — each
composed from existing mechanisms rather than a parallel system:

- **Intake:** `/contact` + `admin@civicaatlas.org`, the data-dispute intake,
  `/civica-index/corrections`, and the security path.
- **Authenticate / no PII exposure:** standing + specifics required; a party's
  contact details are never shared or published.
- **Evidence:** research-evidence retention (DAT-016) append-only before/after
  history with reason/actor/time.
- **Containment:** reversible `withheld` value-state and rights-manifest / NC
  flags; nothing deleted.
- **Review:** counsel escalation (BRD-003/010, manual) for legal questions;
  editorial correction path for factual ones.
- **Public correction:** the `/policies` correction/retraction/supersession
  contract (CLM-016) — the fact public, the complainant private.

A dated tabletop note records the two external dependencies not yet engaged
(counsel review; confirmed real intake delivery, queued under BRD-014).

Doc-only; the master-plan validator passes.
