# ATL-018 Index presentation release note

**Date:** 2026-07-18

The protected Civica Data and Scores presentation surfaces now preserve a
rejected Atlas query as a named temporarily-unavailable state. They do not
change any Index input, transformation, weight, missingness policy,
uncertainty policy, band, rank, value, source, or release selection.

The only reader effect is to distinguish unavailable score data from a
successful empty source-native score result.
