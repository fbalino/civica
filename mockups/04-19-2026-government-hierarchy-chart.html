Pane 3 · Detail (this chart)

The hierarchy chart renders inside pane 3 on the /countries/[slug] page, replacing the plain-text Executive / Legislative / Judicial bullets currently shown in the Full structure section.

Design spec

Data model (additive)

Current schema supports body → office (flat). To render deeper trees we need two additive columns:

  • government_bodies.parent_body_iduuid · null
  • offices.reports_to_office_iduuid · null
  • government_bodies.branchextend: monarchy
  • offices.office_typeused to style nodes

Chart must render gracefully when these are null (falls back to today's flat columns).

Tokens & theming

  • Executive--color-branch-executive
  • Legislative--color-branch-legislative
  • Judicial--color-branch-judicial
  • Monarchy (new)#b48bff proposed
  • Node card--color-surface-secondary
  • Connectorscolor-mix(branch, 35%)

Dark/light use the existing Civica paper ↔ ink tokens. No new base palette.

Interactions

  • Hover node→ popover card
  • Click ▾→ collapse subtree
  • Click node→ navigate to profile
  • Expand all / Collapse all→ toolbar
  • Keyboard↑ ↓ ← → between nodes
  • Mobilehorizontal scroll, columns min 260px

Node variants

  • Office (holder)title + person
  • Office (vacant)title only
  • Groupe.g. "Cabinet · 15"
  • Chamberseats + party bar
  • Bodybranch root

Layout rules

  • Columnsone per top-level branch
  • Min col width280px · scroll on overflow
  • Max tree depthno hard cap · collapse by default at depth ≥ 3
  • Initial expansionbranch root + direct children
  • Connectors1px CSS-only (no SVG lib)

Accessibility

  • Tree rolerole="tree"
  • Nodesrole="treeitem"
  • Aria expandedon each collapsible
  • Color + shapenot color alone for branches
  • Min contrastAA on both themes
Implementation notes for engineering
  • Replace the SVG body of GovStructureDiagram.tsx with semantic <ul role="tree"> markup.
  • Keep the props signature; add optional parentBodyId / reportsToOfficeId to the input types.
  • Tree layout is pure CSS (no d3). Connectors use ::before / ::after on each <li>.
  • Hover card becomes a popover component so it can be keyboard-focusable (not hover-only).
  • Chamber nodes reuse HemicycleChart data for the party bar.
  • Monarchy branch key is opt-in; only show the column when at least one body has branch = "monarchy".
  • Collapse state is local (React useState). No URL sync for v1.
  • Mobile: horizontal scroll on the .chart-canvas, sticky branch headers at top.
