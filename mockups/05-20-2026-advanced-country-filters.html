Lightweight URL state

Every selection is serialised into the query string as comma-joined slugs — one key per facet. The page stays a server component; filtering re-runs on the server from searchParams, no client store, no schema change.

/countries

Shareable, bookmarkable, and back-button safe. Empty facets are simply absent from the URL.

What changed vs. today

  • Continent goes from single-select tabs → multi-select chips.
  • Three new facets reuse fields already on the country row — government category, population, democracy index. No new columns.
  • Chips show a live count of how many countries match each value, so dead-end filters are visible before you click.
  • An applied-filters row summarises state and gives one-click removal + “clear all”.
  • Logic: OR within a facet, AND across facets — the predictable default for faceted browse.
