# K3 Power and Transfer Ledger prototype v1

This private prototype extracts only sourced current-executive tenure states. It does not calculate historical alternation, electoral transfers, or term-limit compliance because the current database lacks ended predecessor terms, validated election-to-term links, and coded constitutional term histories.

Every retained prototype row has at least one term statement URL. Ambiguous executive identity remains contested. No row contains a score, grade, or rank. The public rulebook explains the coding and nonclaims; current country rows remain private until validation passes.
